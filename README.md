# MoreauNeveuDSBeerRatingML
Machine learning project to predict beer ratings based on flavor characteristics using Random Forest.

- NumPy
- Matplotlib
- Scikit-learn

# Model
- Random Forest Regressor
- R² ≈ 0.45
- MSE ≈ 0.099

#Key Insights
- Body and Malty are strong predictors of high ratings
- Sour negatively impacts ratings
- Model captures general trends but struggles with extreme values

# Files
- `Main.py`: main script
- `beer_profile_and_ratings.csv`: dataset
